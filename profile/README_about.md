## 🤗&nbsp; Welcome to Area +55 🇧🇷

If you enjoy the indie hacker lifestyle and prefer going solo, that's totally fine. But if you're not really into it and have started feeling discouraged by working alone — no one to interact with, no motivation to explain everything again to your [rubber duck](https://en.wikipedia.org/wiki/Rubber_duck_debugging) — then being part of a squad might help.

I'm starting development on a few apps and decided to embrace crowdsourcing (and AI). In case anyone feels like joining in, I created this GitHub organization. The doors are open to anyone tired of coding alone who wants to be part of a dev community.


## 🤝&nbsp; Collaboration over Coordination

There's no boss, manager, scrum master, tech lead, chief, or any other authority figure here… Work is done following the [e**X**treme **P**rogramming](https://en.wikipedia.org/wiki/Extreme_programming) methodology. XP has the advantage of creating a sense of shared ownership — no part of the code has an "owner".

If you decide to join any of the projects, I ask that you mention if you have any specialty. Everyone is welcome: UX/UI Designer, Front-end Dev, Mobile Dev, Back-end Dev, Data Analytics, AI Engineer, Cloud Architect, DevOps... But if you do all of that just vibing, that's totally fine too.


## 🫵&nbsp; BYOP: Bring Your Own Project

If you're already working on a project and would like to develop it within the community, bring your repository along. Get in touch via [WhatsApp](https://wa.me/teknolista) or [Telegram](https://t.me/teknolista) so I can incorporate your project into this organization. You will, however, need to answer a few questions just to check whether the project is a good fit.
